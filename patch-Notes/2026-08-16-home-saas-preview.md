# 홈 SaaS 스타일 시안 추가

## 완료 항목

- `docs/design/previews/pc/home-saas.html`에 SaaS 스타일의 PC 홈 시안을 추가했습니다.
- 기존 홈 시안의 정보 구조(헤더, 시공 사례, 사용 제품, 전화 문의, 푸터)를 유지했습니다.
- `public/images/cases/`의 실제 시공 사진을 Hero와 사례 카드에 연결했습니다.

## 변경 사항

- Hero에 그라데이션, 반투명 상담 안내 패널, 강조 CTA를 적용했습니다.
- 시공 사례와 제품 소개는 카드형 레이아웃으로 재구성했습니다.
- 실제 실적·고객사·인증 등 제공되지 않은 사실은 추가하지 않았습니다.

## 검증

- HTML의 `public/images/cases/` 상대 이미지 경로를 확인했습니다.

## 다음 입력

- 실제 서비스 적용 전에는 시안의 링크와 전화 문의 흐름을 페이지 구현에 연결합니다.
