## 추가 1 — 기획자

- 파일: `docs/requirements/*-req.md`, `docs/plan/*-plan.md`, `docs/design/*-design.md`, `docs/develop/*-dev.md`
- 내용: 요구사항, 기획, 디자인, 개발 산출물을 공통 및 페이지별 문서로 분리할 수 있도록 기본 문서 구조를 생성했다.
- 이유: 역할과 페이지가 섞인 기존 문서를 책임별로 분류하기 위한 대상 구조가 필요하다는 사용자 요청을 반영했다.
- 관련: 사용자 요청 — 요구사항·기획 분리 구조화
- 검증: 요청된 파일의 존재 여부와 Git 공백 오류를 확인했다.

## 수정 2 — 기획자

- 파일: `docs/requirements/0*-*.md`, `docs/plan/0*-*.md`, `docs/design/0*-*.md`, `docs/develop/0*-*.md`
- 내용: 파일 탐색기와 문서 목록에서 역할별 문서가 의도한 순서로 표시되도록 숫자 접두사를 추가했다.
- 이유: 파일명이 알파벳순으로 정렬되어 공통·페이지 문서의 읽기 순서가 유지되지 않는 문제를 해결했다.
- 관련: 사용자 요청 — 문서 파일 순서 정렬
- 검증: 기존 이름이 남지 않았는지와 새 이름의 정렬 순서를 확인했다.
