# 산출물 폴더 구조

```txt

agents                            # 역할별 규칙과 권한
├─ AGENTS.md                      # 에이전트 산출물·권한 공통 규칙
├─ designer.toml                  # 디자이너 역할 설정
├─ frontend-developer.toml        # 프론트엔드 개발자 역할 설정
├─ planner.toml                   # 기획자 역할 설정
└─ reviewer.toml                  # 리뷰어 역할 설정

```

# 산출물 문서 작성 규칙

- 각 페이지와 역할을 합친 파일 이름으로 문서를 만든다. (예 : 기획자가 웰컴페이지를 만든다 => welcomePage-plan.md)
- 모든 페이지에는 기획 / 디자인 / 개발의 산출물 문서가 있어야한다.
- 산출물의 결과물은 다른 역할이 보았을때 바로 이해할 수 있게 간단하지만 명확한 구조로 작성한다.

# 산출물 접근 권한

- 모든 역할은 모든 산출물에 접근 권한이 있다.
- 각 역할에 해당하는 문서는 추가/수정/생성/삭제 권한이 있다.
- 현재 역할 산출물 외에는 only-read만 가능하다.

# 산출물 외 CRUD 권한

- 일반적으로는 허용하지 않는다.
- 필요시에 사용자에 의해 허락을 요청할 수 있다. 허락시 특정 폴더 & 파일에 대해 CRUD할 권한을 가진다.
