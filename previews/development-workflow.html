개발 흐름 요약

개발 시작 뒤 GK 산업 사이트를 만들고, 확인하고, 배포하는 순서입니다.

내 컴퓨터에서 작업하는 순서

1패키지 설치

프로젝트에 필요한 도구를 한 번 설치합니다.

2화면 실행

내 컴퓨터에서 사이트를 열어 확인합니다.

3코드 검사

ESLint로 흔한 작성 실수를 확인합니다.

4규칙 검사

필터·페이지 계산 같은 핵심 규칙을 확인합니다.

5배포용 생성

JSON과 페이지를 검사하고 정적 파일을 만듭니다.

사용할 명령

npm install       # 필요한 패키지 설치
npm run dev       # 내 컴퓨터에서 사이트 실행
npm run lint      # 코드 작성 실수 검사
npm test          # 핵심 데이터 규칙 검사
npm run build     # 정적 배포용 파일 생성과 JSON 검사

검사 실패가 발견되면 자동으로 고치지 않습니다. 문제 내용과 수정 계획을 먼저 보고하고, 승인 후에만 수정합니다.

콘텐츠 변경부터 실제 배포까지

작업 브랜치변경 전 별도 작업 공간을 만듭니다.
JSON·사진 수정사례·제품 내용과 사진을 추가하거나 바꿉니다.
PR 미리보기Cloudflare Pages 주소에서 먼저 확인합니다.
main 머지고객이 보는 사이트가 자동으로 갱신됩니다.
