# GK 산업 웹사이트

GK 산업의 바닥 시공 사례와 시공 시 사용 제품을 소개하고 전화 문의로 연결하는 정적 웹사이트 프로젝트입니다.

## 개발 시작 후 기본 흐름

아래 명령은 개발 단계에서 Next.js 프로젝트와 npm 명령을 실제로 만든 뒤 사용할 표준 흐름입니다.

```bash
npm install       # 필요한 패키지 설치
npm run dev       # 내 컴퓨터에서 사이트 실행
npm run build     # 프로덕션 빌드 확인
```

자세한 개발 문서는 `docs/development/`에서 관리합니다.
