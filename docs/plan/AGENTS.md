# 해당 파일은 requirements에 있는 요구사항들을 기획하는 역할이다.

- 번호+적용대상+req => 번호+적용대상+plan이 해당 요구사항의 기획파일이다.
- 예시로 01-common-req.md와 같은 요구사항 파일은 01-common-plan.md 파일에 기획내용을 적으면 된다.
- 사용자의 인터뷰에 따른 요구사항의 상태를 변경한다.

# 작성 규칙

- 우선순위 : 디자인 / 개발시 우선적으로 진행해야되는것.
- 제목 : 요구사항에 적혀있는 내용 복사
- 구현 상태 : 구현/미구현이 존재
- 구현 방법 : 요구사항에 적혀있는 기능을 어떻게 구현할건지 써두는것

```txt

# NFR-common-999

- 우선순위 : 상
- 요구사항 : 필터 버튼 기능
- 구현 상태 : 미구현

## 구현 방법

- 필터는 중복이되어선 안된다. 단, 한 페이지에 A필터, B필터가 있으면 A와B는 중첩이 된다.
- 전체 버튼으로 초기화를 진행한다.

```
