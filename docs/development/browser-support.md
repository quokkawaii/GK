# 브라우저 지원 기준

| 브라우저 | 지원 기준 |
| --- | --- |
| Chrome | 최근 3년 안의 버전 |
| Edge | 최근 3년 안의 버전 |
| Firefox | 최근 3년 안의 버전 |
| Safari | 최근 2년 안의 버전 |
| 모바일 Chrome | 최근 3년 안의 버전 |
| 모바일 Safari | 최근 2년 안의 버전 |
| Internet Explorer | 지원하지 않음 |

## 확인 범위

- 메뉴와 페이지 이동
- 사례·제품 필터와 페이지 번호
- 사진 보기와 확대
- 전화 문의 링크
- 텍스트와 사진의 기본 표시

오래된 브라우저에서 화면 모양이 일부 달라질 수 있어도, 기본 정보와 전화 문의는 가능한 범위에서 유지한다.
