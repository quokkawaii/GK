# 방문 통계 계획

## 도구

- Cloudflare Web Analytics
- 적용 위치: Cloudflare Pages 프로젝트의 **Metrics → Web Analytics**
- 적용 방식: 대시보드에서 활성화하면 다음 배포 때 필요한 스크립트가 자동으로 적용된다.

## 확인할 정보

- 방문 수와 페이지 조회 수
- 많이 본 페이지 경로
- 외부 유입 경로
- 국가, 기기 유형, 브라우저
- 페이지 로딩 성능

## 초기 제외 범위

- 개인 식별 목적의 데이터 수집
- 버튼 클릭 등 맞춤 이벤트
- UTM 쿼리 문자열 분석

Cloudflare는 Web Analytics가 방문자의 개인 데이터를 수집하거나 사용하지 않는다고 안내한다. 대시보드에서 현재 최근 6개월의 데이터를 확인할 수 있다.
