# PR 자동 검사 계획

개발 단계에서 GitHub Actions 워크플로를 추가해 PR마다 아래 검사를 실행한다.

| 순서 | 검사 | 목적 |
| --- | --- | --- |
| 1 | ESLint | 코드 작성 실수 확인 |
| 2 | Vitest | 태그 필터·페이지 계산 등 핵심 데이터 규칙 확인 |
| 3 | Next.js 정적 빌드 | JSON 데이터와 페이지 생성이 배포 가능한지 확인 |

## 실패 시 규칙

검사가 실패하면 개발자는 자동으로 수정하지 않는다. 실패한 검사, 실제 결과, 영향, 원인 추정, 수정하려는 파일과 조치를 사용자에게 먼저 보고하고 승인받은 뒤에만 수정한다.

## 개발 단계 구현 위치

`/.github/workflows/ci.yml`

이 파일은 개발 단계에서 실제 코드와 npm 명령이 확정된 뒤에 만든다.
