# docs 폴더 구조

```text
docs
├─ AGENTS.md                 # 해당 파일
├─ requirements             # 요구사항 문서
│  ├─ 01-common-req.md
│  ├─ 02-home-req.md
│  ├─ 03-cases-req.md
│  ├─ 04-products-req.md
│  └─ 05-about-req.md
├─ plan                     # 기획자 문서
│  ├─ 01-common-plan.md
│  ├─ 02-home-plan.md
│  ├─ 03-cases-plan.md
│  ├─ 04-products-plan.md
│  └─ 05-about-plan.md
├─ design                   # 디자이너 문서와 시안
│  ├─ 01-common-design.md
│  ├─ 02-home-design.md
│  ├─ 03-cases-design.md
│  ├─ 04-products-design.md
│  └─ 05-about-design.md
└─ develop                  # 개발자 문서
   ├─ 01-common-dev.md
   ├─ 02-deployment-dev.md
   ├─ 03-homePage-dev.md
   ├─ 04-casesPage-dev.md
   ├─ 05-productsPage-dev.md
   └─ 06-aboutPage-dev.md
```

- 기존 문서와 하위 폴더는 분류·이관이 끝날 때까지 유지한다.
- 각 역할은 자신의 산출물 문서만 작성·수정한다.
