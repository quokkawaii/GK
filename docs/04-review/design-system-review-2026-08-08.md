# 디자인 시스템 재검토 — 2026-08-08

## 대상

- `docs/02-design/design-system.md`
- `previews/design/pc/`의 실제 적용 후보 화면
- `previews/design/mobile/`의 실제 적용 후보 화면
- 기존 승인된 필터·사진·모바일 기능 동등성 결정

## 판정

**CHANGES REQUIRED**

디자인 시스템 자체는 색상·글자·간격·공통 요소·사진·반응형 기준을 빠짐없이 정리했다. 하지만 기존 실제 적용 후보 시안 일부가 새 기준과 다르다. 개발 전에 시안을 디자인 시스템으로 맞춘 뒤 재검토가 필요하다.

## 지적 사항

### REV-016 — 사례·제품 목록 카드 구조와 사진 비율 불일치 (높음)

- 대상: `previews/design/pc/case-list.html`, `previews/design/mobile/case-list.html`, `previews/design/pc/product-list.html`, `previews/design/mobile/product-list.html`
- 근거: 디자인 시스템은 사례·제품 목록 카드를 2열·4:3 사진으로 정했다. PC 제품 목록은 3열이며, 모바일 제품 목록은 사진 왼쪽·글자 오른쪽의 가로 카드다. PC·모바일 사례 목록의 사진 높이도 고정값이라 4:3 비율과 맞지 않는다.
- 영향: 같은 목록 화면이라도 제품·사례와 PC·모바일마다 사진 크기와 카드 구조가 달라, 사용자가 승인한 공통 요소·사진 기준을 구현에 적용할 수 없다.
- 권장 조치: 사례·제품 목록을 PC·모바일 모두 2열 카드로 통일하고, 목록 사진을 4:3 비율로 수정한다. 페이지당 4개 사례 규칙은 유지한다.
- 관련: DEC-046, DEC-047, DEC-048

### REV-017 — 선택된 필터의 색상 규칙 불일치 (높음)

- 대상: `previews/design/pc/case-list.html`, `previews/design/mobile/case-list.html`, `previews/design/pc/product-list.html`, `previews/design/mobile/product-list.html`
- 근거: 디자인 시스템은 선택된 필터를 연한 주황 배경·주황 테두리·진한 주황 글자로 정했다. 실제 후보 시안은 선택된 필터를 주황 배경·흰 글자로 표시한다.
- 영향: 필터와 전화 문의 버튼의 시각적 우선순위가 겹치고, 확정한 선택 상태 규칙과 구현 기준이 달라진다.
- 권장 조치: 실제 후보 시안의 선택 필터를 디자인 시스템의 연한 주황 선택 상태로 통일한다.
- 관련: DEC-044, DEC-046

### REV-018 — 글자·누르는 영역 기준 미반영 (중간)

- 대상: `previews/design/pc/`, `previews/design/mobile/`의 실제 적용 후보 화면
- 근거: 실제 후보 시안은 `Arial` 중심 글꼴과 기존 글자 크기·굵기를 사용한다. 페이지 번호와 전화 문의 버튼도 일부 화면에서 44px 최소 높이 기준보다 작다.
- 영향: 새로 확정한 Pretendard 기반 글자 체계와 공통 버튼 기준이 실제 구현 기준으로 이어지지 않는다. 모바일에서 누르기 어려운 작은 버튼이 남을 수 있다.
- 권장 조치: 실제 후보 시안의 글꼴·글자 단계·버튼 최소 높이를 디자인 시스템 표에 맞춘다.
- 관련: DEC-045, DEC-046

### REV-019 — 상세 갤러리의 원본 비율 보존 기준 미반영 (중간)

- 대상: `previews/design/pc/case-detail.html`, `previews/design/mobile/case-detail.html`
- 근거: 디자인 시스템은 상세 사진을 원본 비율 유지 방식으로 정했으나, 실제 후보 시안은 고정 높이 배경 영역으로 사진을 표현한다.
- 영향: 세로 사진이나 가로 사진의 실제 비율을 보존하는 구현 기준이 시안에 드러나지 않는다.
- 권장 조치: 갤러리 시안을 어두운 배경 안에서 사진 전체가 보이는 방식으로 수정하고, 기존 화살표·위치·썸네일 기능은 유지한다.
- 관련: DEC-047

## 통과 항목

- 색상 체계는 기존 승인 시안의 밝은 배경·진한 글자·주황 강조색 흐름과 일치한다.
- PC 사례 목록의 메뉴는 헤더 아래 고정 메뉴와 가로 이동 필터를 보여준다.
- 모바일 공통 메뉴·전화 문의 연결은 이전 리뷰의 통과 상태를 유지한다.
- 검색창을 추가하지 않고, 장소·자재 또는 공법 필터만 제공하는 요구사항을 유지한다.

## 검증 메모

- 파일 소스 기준으로 CSS·HTML 구조를 대조했다.
- 이전에 로컬 브라우저 자동 연결 권한 오류가 있었으므로, 이번 검토에서는 같은 자동 브라우저 검증을 반복하지 않았다.

### REV-020 — 디자인 시스템 글꼴·조작 영역 적용 범위 불완전 (중간)

- 대상: `previews/design/pc/home.html`, `previews/design/mobile/home.html`, `previews/design/pc/about.html`, `previews/design/mobile/about.html`, `previews/design/pc/product-detail.html`, `previews/design/mobile/product-detail.html`
- 문제: 목록과 사례 상세는 새 기준으로 맞췄지만, 위 화면들은 아직 Arial 중심 글꼴을 사용한다. 전화 문의·주요 이동 버튼도 일부가 44px 최소 높이 및 14px·600 글자 기준에 못 미친다.
- 근거: 디자인 시스템의 글자·버튼 공통 기준은 화면 일부가 아니라 실제 적용 후보 전 화면에 적용하는 기준이다.
- 영향: 같은 서비스 안에서 페이지마다 글자와 누르는 영역의 감각이 달라지고, 개발자가 어느 화면을 기준으로 구현할지 혼동할 수 있다.
- 권장 조치: 위 여섯 화면의 글꼴을 Pretendard 기준으로 바꾸고, 전화 문의·주요 이동 버튼에 44px 최소 높이와 공통 버튼 글자 규칙을 적용한다.
- 관련: DEC-045, DEC-046

### 검증 메모

- 목록 네 화면에서 2열 구조·`aspect-ratio:4/3`·선택 필터 색상·44px 페이지 번호를 소스 기준으로 확인했다.
- 사례 상세 두 화면에서 Pretendard·44px 조작 영역·진한 갤러리 배경·`contain` 표시 규칙과 기존 갤러리 요소의 유지 여부를 확인했다.
- 로컬 브라우저 자동 연결은 이전 권한 오류와 같은 조건이라 반복 실행하지 않았다.
