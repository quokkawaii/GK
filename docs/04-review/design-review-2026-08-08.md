# 디자인 리뷰 — 2026-08-08

## 대상

- `previews/design/pc/`의 홈·시공 사례·사용 제품·회사 소개 화면
- `previews/design/mobile/`의 같은 화면 범위
- `docs/02-design/mobile-parity.md`
- 확정된 요구사항 `REQ-001`, `REQ-005`~`REQ-008`, `REQ-010`, `REQ-011`

## 판정

**CHANGES REQUIRED**

화면 구성과 사진·필터·전화 문의의 시각적 배치는 대체로 확정 요구사항과 맞다. 다만 사용자가 명시한 “모바일과 PC의 모든 기능 동일” 원칙에 대해, 모바일 화면 간 메뉴와 전화 문의 동작이 일관되게 설계되지 않았다.

## 지적 사항

### REV-013 — 모바일 메뉴 기능 누락 (높음)

- 대상: `previews/design/mobile/case-list.html`, `case-detail.html`, `product-list.html`, `product-detail.html`, `about.html`
- 근거: 모바일 홈에만 오른쪽 메뉴 패널과 열기·닫기 동작이 있다. 나머지 화면은 메뉴 아이콘이 없거나, 있어도 메뉴 패널과 연결되지 않는다.
- 영향: 모바일에서 현재 페이지가 홈이 아닐 때 홈·시공 사례·사용 제품·회사 소개로 이동하는 공통 메뉴 기능이 보장되지 않는다.
- 권장 조치: 모바일 홈의 헤더·오른쪽 메뉴 패널·열기/닫기 동작을 모든 모바일 화면에 공통 적용한다.
- 관련: `REQ-001`, `docs/02-design/mobile-parity.md`

### REV-014 — 모바일 전화 문의 동작 불일치 (높음)

- 대상: `previews/design/mobile/case-list.html`, `case-detail.html`, `product-list.html`, `product-detail.html`, `about.html`
- 근거: `tel:` 연결은 `mobile/home.html`에만 있고, 다른 모바일 화면의 `전화 문의` 표시는 연결 동작이 없는 텍스트다.
- 영향: 핵심 목표인 전화 문의가 방문 위치에 따라 작동하지 않을 수 있다.
- 권장 조치: 모든 모바일 화면의 전화 문의 UI를 동일한 `tel:` 연결로 설계한다. PC는 번호 표시 또는 전화 안내로 유지한다.
- 관련: `REQ-010`, `docs/02-design/mobile-parity.md`

### REV-015 — 사용 제품 상세 정보 표현 보류 상태 (중간)

- 대상: `previews/design/pc/product-detail.html`, `previews/design/mobile/product-detail.html`
- 근거: 사용자는 제품 상세의 정보 표현을 추가 검토 대상으로 남겼고, `mobile-parity.md`에도 보류 상태로 기록되어 있다.
- 영향: 제품 상세의 정보 순서와 문구를 구현 기준으로 확정할 수 없다.
- 권장 조치: 개발 전 제품 상세의 사진·정보 표·전화 문의 구성에 대한 사용자 최종 승인을 받거나, 해당 화면을 구현 범위에서 명시적으로 보류한다.
- 관련: `REQ-007`

## 통과 항목

- 시공 사례 목록은 장소·자재 분리, 다중 선택 AND 필터, 초기화, 페이지 번호 흐름을 보여 준다.
- 시공 사례 상세는 여러 사진, 화살표, 사진 위치, 썸네일, 설명·시공 정보를 포함한다.
- 제품은 판매 정보 없이 소개 정보 중심으로 구성되어 있다.
- 회사 소개는 확인되지 않은 실적·인증을 넣지 않고 간략한 소개와 전화 문의로 구성되어 있다.
- 웰컴 페이지는 회사 소개 섹션 없이 시공 사례와 사용 제품을 우선 노출한다.
