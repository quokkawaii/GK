# 모바일 화면 기능 동일 원칙

## 결정

- 모바일과 PC는 제공 기능 범위가 동일해야 한다.
- 화면 폭에 따라 배치와 조작 방식만 달라질 수 있으며, 메뉴·목록·필터·페이지 이동·상세 정보·사진 보기·전화 문의는 빠지지 않는다.

## 적용 기준

| 화면 | PC 기능 | 모바일 적용 방식 |
| --- | --- | --- |
| 웰컴 페이지 | 시공 사례·사용 제품·외부 채널·전화 문의 | 같은 섹션을 세로 배치하고 햄버거 메뉴 사용 |
| 시공 사례 목록 | 장소·자재 필터, 다중 선택, 페이지 번호, 한 페이지당 4개 카드 | 가로 스와이프·드래그 필터, 같은 페이지 번호와 2×2 카드 |
| 시공 사례 상세 | 사진 이동·확대, 썸네일, 상세 정보 | 같은 사진 조작과 상세 정보 |
| 사용 제품 목록 | 공법 필터, 제품 카드 | 같은 공법 필터와 제품 카드 |
| 사용 제품 상세 | 제품 정보, 전화 문의 | 같은 제품 정보와 전화 문의 |
| 회사 소개 | 소개, 시공 범위, 전화 문의 | 같은 소개, 시공 범위, 전화 문의 |

## 상태

- 사용 제품 상세은 현재의 사진·정보 표·전화 문의 구성으로 확정한다. 실제 제품별 문구와 면적 수치는 이후 데이터로 교체한다.
- 모바일은 PC와 기능을 맞추되, 세부 디자인은 이후 피드백으로 조정한다.
