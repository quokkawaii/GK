# 디자인 시스템

이 문서는 GK 산업 사이트 화면에 공통으로 적용할 디자인 기준을 기록한다. 실제 코드 값은 개발 단계에서 `styles/tokens.css`에 같은 내용으로 적용한다.

## 정할 항목

| 영역 | 정할 내용 | 상태 |
| --- | --- | --- |
| 색상 | 기본 배경, 글자, 강조색, 테두리, 경고색 | 확정 |
| 글자 | 제목·본문·보조 문구 크기와 굵기 | 확정 |
| 간격 | 카드·섹션·화면 여백의 공통 단위 | 확정 |
| 모서리·테두리 | 카드와 버튼의 모서리, 선 두께 | 확정 |
| 버튼 | 전화 문의, 일반 버튼, 필터 버튼 상태 | 확정 |
| 사진 | 목록·상세 사진 비율, 대체 텍스트 기준 | 확정 |
| 반응형 | PC·모바일 전환 기준과 화면별 배치 | 확정 |

## 적용 원칙

- 시공 사진이 가장 먼저 보이도록 장식 요소를 과도하게 늘리지 않는다.
- 전화 문의는 강조색을 사용하되, 화면 전체에서 같은 방식으로 표시한다.
- 디자인 값은 화면마다 임의로 새로 만들지 않고 이 문서와 `styles/tokens.css`의 값을 재사용한다.

## 색상

| 이름 | 값 | 사용 위치 |
| --- | --- | --- |
| 전체 배경 | `#F1F1EF` | 페이지 바깥 배경 |
| 카드·내용 배경 | `#FFFFFF` | 카드, 본문, 필터 영역 |
| 주요 글자 | `#242424` | 제목과 본문 기본 글자 |
| 보조 글자 | `#606060` | 설명과 보조 정보 |
| 테두리 | `#DDDDDA` | 카드, 필터, 구분선 |
| 강조색 | `#E36F3F` | 전화 문의, 선택 필터, 태그 |
| 강조 배경 | `#FFF4EF` | 선택 상태와 안내 영역 |
| 진한 영역 | `#252525` | 히어로와 진한 안내 영역 |

강조색은 사용자의 시선을 안내해야 하는 곳에만 제한적으로 사용한다. 넓은 배경에는 쓰지 않아 시공 사진보다 강하게 보이지 않게 한다.

## 글자

- 기본 글꼴: Pretendard 우선, 운영체제 기본 한글 고딕을 대체 글꼴로 사용한다.
- 굵기: 본문 `400`, 강조·카드 제목 `600`, 큰 제목 `700`으로 제한한다.
- 실제 웹폰트 파일의 제공 방식은 개발 단계에서 파일 용량을 확인한 뒤 결정한다.

| 구분 | PC | 모바일 | 굵기 |
| --- | --- | --- | --- |
| 대표 제목 | 40px / 줄 간격 48px | 32px / 40px | 700 |
| 페이지 제목 | 32px / 40px | 28px / 36px | 700 |
| 구역 제목 | 24px / 32px | 22px / 30px | 700 |
| 카드 제목 | 18px / 25px | 17px / 24px | 600 |
| 본문 | 16px / 26px | 15px / 24px | 400 |
| 보조 문구 | 14px / 22px | 13px / 20px | 400 |
| 태그 | 12px / 18px | 12px / 18px | 600 |

## 간격

모든 여백은 아래 단위만 사용한다. 임의의 숫자를 새로 만들지 않는다.

`4px · 8px · 12px · 16px · 24px · 32px · 48px · 64px`

- 같은 카드 안 요소: 4px~16px
- 카드와 카드 사이: 12px~16px
- 구역 안 여백: 24px~32px
- 화면 구역 사이: 48px~64px

## 공통 요소

### 모서리와 테두리

- 카드·필터·버튼은 둥근 모서리를 사용하지 않고 직선 형태로 유지한다.
- 기본 테두리는 `#DDDDDA` 1px을 사용한다.
- 진한 안내 영역만 `#252525` 배경을 사용한다.

### 버튼

| 구분 | 모양 | 용도 |
| --- | --- | --- |
| 전화 문의 | 주황 배경·흰 글자 | 가장 중요한 전화 문의 |
| 진한 버튼 | 진한 배경·흰 글자 | 시공 사례 보기 같은 주요 이동 |
| 일반 버튼 | 흰 배경·회색 테두리 | 사용 제품 보기, 일반 이동 |
| 글자 버튼 | 배경·테두리 없이 밑줄 | 회사 소개 등 보조 이동 |

- 버튼과 페이지 번호는 최소 높이 44px을 사용한다.
- 버튼 글자는 14px, 굵기 600을 사용한다.

### 필터와 카드

- 선택되지 않은 필터는 흰 배경·회색 테두리로 표시한다.
- 선택된 필터는 연한 주황 배경·주황 테두리·진한 주황 글자로 표시한다.
- 필터 초기화는 태그 필터 제목 옆에 밑줄 글자 버튼으로 둔다.
- 사진 카드는 1px 테두리, 사진, 태그, 제목, 짧은 설명 순서로 구성한다.
- 목록 카드 전체를 눌러 상세 페이지로 이동한다.

### 페이지 번호

- 페이지 번호는 44px 정사각형 버튼으로 둔다.
- 현재 페이지는 주황 배경·흰 글자로 표시하고, 나머지는 흰 배경·회색 테두리를 사용한다.

## 사진

| 위치 | 표시 기준 |
| --- | --- |
| 시공 사례·제품 목록 카드 | 4:3 비율로 카드 영역을 채워 표시 |
| 웰컴 페이지 대표 사진 | 16:10 비율로 넓게 표시 |
| 상세 갤러리 | 원본 비율을 유지하고 사진을 자르지 않음 |
| 상세 썸네일 | 4:3 비율, 현재 사진은 주황 테두리 |

- 상세 갤러리에는 좌우 이동 버튼, 현재 위치(`1 / 6` 등), 썸네일을 항상 표시한다.
- 가로·세로 사진은 상세 갤러리의 어두운 여백 안에서 모두 보이게 표시한다.
- 모든 사진에는 현장·시공 내용을 설명하는 대체 문구를 입력한다.

## 반응형

| 화면 폭 | 구분 | 적용 기준 |
| --- | --- | --- |
| 767px 이하 | 모바일 | 햄버거 메뉴, 화면 좌우 여백 16px, 목록 카드 2열 |
| 768px~1023px | 태블릿 | PC와 모바일 사이의 여백·카드 폭을 자연스럽게 조정 |
| 1024px 이상 | 데스크톱 | 헤더 아래 고정 메뉴, 최대 내용 폭 1,180px, 목록 카드 2열 |

- PC와 모바일은 메뉴, 필터, 페이지 번호, 사진 갤러리, 상세 정보, 전화 문의 등 같은 기능을 모두 제공한다.
- 모바일에서는 메뉴를 햄버거 버튼으로 열고, 필터 옵션은 가로 스크롤·드래그·마우스 휠로 이동한다.
- 시공 사례와 사용 제품 목록은 모바일에서도 카드 2열을 유지하고, 한 페이지에 4개씩 표시한다.
- 화면 폭에 따라 사진·글자·여백만 줄이거나 재배치하며, 기능을 빼지 않는다.
