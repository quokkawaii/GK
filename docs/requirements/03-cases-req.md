# 시공 사례 요구사항

## 기능 요구사항 (REQ)

# REQ-common-028

- 상태 : DECIDED
- 제목 : 시공 사례 상세의 독립 공개 URL·색인 미제공

## 완료 기준

- 주소 표시줄은 시공 사례 기본 목록 URL을 유지한다.
- 시공 사례 상세에는 사례별 독립 URL, canonical URL, Open Graph 정보, 사이트맵 항목을 제공하지 않는다.

------------------------

# REQ-common-030

- 상태 : DECIDED
- 제목 : 시공 사례 필터 변경 뒤 첫 페이지 결과 표시

## 완료 기준

- 시공 사례 페이지에서 장소 또는 자재 태그를 추가·해제하면 현재 페이지 번호를 1페이지로 초기화한다.
- 필터 변경 뒤 `전체 N건 / 1페이지` 결과 요약이 고정 헤더에 가려지지 않도록 화면 상단에 표시된다.
- 결과 요약 바로 아래에서 새 조건의 첫 사례 카드 또는 결과 없음 안내를 확인할 수 있다.
- 선택된 장소·자재 태그 토글은 필터 변경 뒤에도 그대로 표시된다.

## 비기능 요구사항 (NFR)

# NFR-common-047

- 상태 : REJECTED
- 제목 : 시공 사례 상세·사진 확대 모달의 초점 흐름

## 완료 기준

- 상세 팝업 또는 사진 확대 뷰어를 열 때 키보드 초점을 내부 요소로 강제로 이동시키지 않는다.
- `Tab`·`Shift+Tab` 초점 순환과 닫은 뒤 원래 카드·사진 조작으로의 초점 복귀를 제공하지 않는다.
- 모달 컨테이너에 대화상자 역할, 모달 상태, 접근 가능한 이름을 추가하지 않는다.
- 디자인 시스템에서 확정한 `Esc` 닫기, 배경 스크롤 잠금, 목록 필터·페이지 번호·스크롤 위치 유지는 유지한다.

------------------------

# NFR-common-054

- 상태 : DECIDED
- 제목 : 사례 상세·사진 확대 팝업의 브라우저 이력 미사용

## 완료 기준

- 사례 카드로 상세 팝업을 열거나, 상세 팝업에서 사진 확대 뷰어를 열어도 주소는 `/cases`로 유지되고 브라우저 이력 항목을 추가하지 않는다.
- 사진 확대 뷰어 또는 상세 팝업이 열려 있을 때 브라우저 뒤로가기를 누르면, 뷰어·팝업을 닫는 동작을 수행하지 않고 `/cases` 직전의 브라우저 이력으로 이동한다.
- 브라우저 앞으로가기로 `/cases`에 다시 도달해도 사례 상세 팝업과 사진 확대 뷰어를 자동으로 다시 열지 않는다.
- 화면의 닫기 버튼·팝업 바깥 영역·PC `Esc`·모바일 아래 시트 끌기 닫기와 목록 상태 유지는 디자인 시스템 기준을 따른다.
