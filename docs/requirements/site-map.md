# GK 산업 사이트맵과 정보 구조

## 1. 페이지 구조

| 경로 | 페이지 목적 | 핵심 정보와 행동 |
| --- | --- | --- |
| `/` | GK 산업의 시공 전문성과 최신 콘텐츠를 빠르게 전달 | 임시 첫 화면 소개, 최근 시공 사례 3개, 사용 제품 3개, 고정 헤더 전화 문의 |
| `/cases` | 방문자가 원하는 시공 사례를 찾게 함 | 현장 유형·공법 다중 태그 필터, 필터 초기화, 최신순 사례 카드 |
| `/products` | 방문자가 시공 시 사용 제품을 찾게 함 | `전체`를 포함한 자재 다중 태그 필터, 제품 이미지·제품명·적합 현장·시공 사례 보기 링크 |
| `/about` | GK 산업의 기본 회사 정보를 제공 | 임시 소개 문구, 임시 주소·사업자 정보, 유튜브·인스타그램 준비 중 안내 |

## 2. 전역 구조

### 헤더

- 데스크톱: GK 산업 로고, 시공 사례, 사용 제품, 회사 소개, 전화 문의.
- 모바일: 로고, 전화 문의, 메뉴 버튼.
- 헤더는 화면 상단에 고정한다.
- 모바일 메뉴는 오른쪽에서 열리는 패널이다.
- 전화 문의 버튼은 모바일에서 전화 연결을 실행하고, PC에서는 대표번호 안내로 보인다.

### 푸터

- GK 산업명, 임시 대표번호, 임시 주소, 임시 사업자 정보.
- 유튜브·인스타그램은 실제 주소 전까지 `준비 중`으로 표시한다.
- 홈의 회사 소개 섹션은 제공하지 않는다. 회사 소개는 독립 페이지에서 제공한다.

## 3. 홈 정보 구조

1. 첫 화면 소개: 임시 제목과 간단한 안내 문구.
2. 최근 시공 사례: 대표 사진·제목·태그가 있는 사례 카드 3개와 `시공 사례 보기` 이동 UI.
3. 시공 시 사용 제품: 제품 이미지·제품명·적합 현장·`시공 사례 보기` 링크가 있는 카드 3개와 `제품 보러가기` 이동 UI.
4. 푸터.

## 4. 목록과 상세 흐름

### 시공 사례

`시공 사례 목록 → 다중 태그 필터 → 선택 태그를 모두 가진 사례만 표시 → 카드 클릭 → 같은 화면의 상세 팝업`

- 카드: 대표 사진, `화성시 공장` 형식의 제목, 태그.
- 숫자 ID 내림차순으로 정렬하며 ID는 고객 화면에 보이지 않는다.
- 상세 팝업은 닫기 버튼 또는 팝업 바깥 영역 클릭으로 닫는다.

### 사용 제품

`사용 제품 목록 → 전체 또는 자재 다중 태그 필터 → 선택 태그를 모두 가진 제품만 표시 → 카드의 시공 사례 보기 링크 클릭 → 해당 자재 태그가 선택된 시공 사례 목록`

- 카드: 제품 이미지, 제품명, 적합 현장, `시공 사례 보기` 링크.
- 필터의 첫 칩은 `전체`다. `전체`를 누르면 선택한 자재 태그를 해제하고 모든 제품을 표시한다.
- 제품 목록에는 별도 `필터 초기화` 버튼을 두지 않는다.
- 이미지가 `null`이면 이미지 영역에 `이미지가 없습니다`를 표시한다.
- 링크는 Zustand에 카드의 자재 태그를 선택한 뒤 `/cases`로 이동한다. 제품 상세 주소는 만들지 않는다.
- 제품 태그는 자재만 사용한다.
