# 웰컴 페이지 기획 요구사항

- 대상 경로: `/`
- 문서 상태: 기획 진행 중
- 작성 역할: 기획자
- 범위: 웰컴 페이지에만 필요한 콘텐츠 구성, 노출 순서, 페이지 안 이동을 정의한다.

## 목적

방문자가 첫 화면에서 실제 시공 결과와 핵심 메시지를 확인하고, 시공 사례·사용 제품·회사 소개를 살펴본 뒤 전화 문의를 시작할 수 있게 한다.

## 범위 제외

- 공통 헤더, 공통 전화 문의 CTA, 모바일 상단 이동, 공통 반응형 수치와 시각 스타일은 이 문서에서 다시 정의하지 않는다.
- 시공 사례 목록과 상세 팝업의 카드·사진 조작, 사용 제품 목록의 필터·페이지 이동은 각 화면 또는 공용 요구사항 범위다.
- 실제 회사 이력, 시공 실적, 고객사, 인증, 대표 사진·문구의 값은 제공 전까지 임의로 작성하지 않는다.

## 적용하는 디자인 기준

- 웰컴 대표 사진의 비율, 사용 제품 미리보기 카드의 공통 카드 재사용, 헤더·전화 CTA·반응형 배치는 `docs/design/design-system.md`를 따른다.
- 색상, 글자, 여백, 버튼, 카드, 화면 폭 기준은 `docs/design/design-system.md`와 `docs/design/references/toss.md`를 따른다.
