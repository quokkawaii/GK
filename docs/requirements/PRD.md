# GK 산업 홈페이지 요구사항 명세

## 사용자 흐름

방문 → 첫 화면의 시공 사례 사진과 소개 확인 → 사례 목록 또는 사용 제품 목록 탐색 → 사례 상세 확인 또는 자재별 사례 보기 → 고정 헤더의 전화 문의 확인 → 모바일에서 전화 연결.

## 기능 요구사항

| ID | 우선순위 | 요구사항 | 완료 기준 |
| --- | --- | --- | --- |
| REQ-001 | 높음 | 모든 페이지에 고정 헤더를 제공한다. | 로고, 시공 사례, 사용 제품, 회사 소개, 전화 문의가 헤더에서 보인다. |
| REQ-002 | 높음 | 모바일 메뉴는 오른쪽 패널로 연다. | 메뉴 버튼으로 열고 닫을 수 있으며, 시공 사례·사용 제품·회사 소개로 이동한다. |
| REQ-003 | 높음 | 첫 화면에 최근 시공 사례 3개를 사진과 함께 노출한다. | 각 사례 카드는 같은 화면의 사례 상세 팝업을 열고, 별도의 `시공 사례 보기` UI는 사례 목록으로 이동한다. |
| REQ-004 | 높음 | 첫 화면에 시공 시 사용 제품 3개를 소개한다. | 제품 이미지, 제품명, 적합 현장 정보, 해당 자재가 적용된 시공 사례 보기 링크와 제품 목록 이동 UI가 보인다. |
| REQ-005 | 높음 | 시공 사례 목록에 다중 태그 필터를 제공한다. | 선택 태그를 모두 가진 사례만 보이고, 필터 초기화가 가능하다. |
| REQ-006 | 높음 | 시공 사례는 숫자 ID 내림차순으로 정렬한다. | 큰 ID의 새 사례가 먼저 보이며 고객 화면에는 ID를 표시하지 않는다. |
| REQ-007 | 높음 | 사례 상세 팝업에 여러 장의 시공 사진을 제공한다. | 사진, 제목, 태그, 장소, 시공 내용, `시공 자재: …` 형식의 사용 제품이 보인다. 닫기 버튼 또는 팝업 바깥 영역 클릭으로 닫는다. |
| REQ-008 | 높음 | 사례 장소는 JSON에 있는 공개용 장소 값을 그대로 표시한다. | 예: `화성시 공장`, `대명항`, `공장`; 고객사명·상세 주소는 표시하지 않고, 없는 지역 정보를 추측해 추가하지 않는다. |
| REQ-009 | 높음 | 사례 제목은 지역·현장 유형·공법으로 구성한다. | 예: `화성시 공장 에폭시`; 불필요한 반복 문구를 넣지 않는다. |
| REQ-010 | 높음 | 사용 제품 목록에 자재 태그 필터를 제공한다. | 첫 항목 `전체`를 누르면 모든 제품을 보이며, 에폭시·우레탄·MMA 등 자재 태그는 여러 개를 선택하면 AND 방식으로 적용한다. 별도 필터 초기화 버튼은 제공하지 않는다. |
| REQ-011 | 높음 | 제품 상세 페이지를 제공하지 않는다. | 제품 목록 카드에는 제품 이미지, 제품명, 적합 현장, `시공 사례 보기` 링크만 제공한다. 링크를 누르면 해당 자재 태그가 선택된 시공 사례 목록으로 이동한다. |
| REQ-012 | 높음 | 전화 문의 버튼을 주요 화면에 제공한다. | 모바일에서는 전화 앱으로 연결되고, PC에서는 대표번호 안내 용도로 보인다. |
| REQ-013 | 보통 | 회사 소개 페이지와 푸터에 임시 회사 정보를 제공한다. | 상단 메뉴에서 회사 소개 페이지로 이동할 수 있다. 실제 정보가 들어오기 전까지 임시 주소·사업자 정보를 표시하고, 데이터 교체가 쉽다. 홈 소개 섹션은 제공하지 않는다. |
| REQ-014 | 보통 | 유튜브·인스타그램은 준비 중 상태를 보여준다. | 실제 링크 전에는 연결하지 않고 준비 중으로 표시한다. |
| REQ-015 | 높음 | 검색 엔진이 페이지 내용을 이해할 수 있게 한다. | 제목·설명·대체 텍스트·사이트맵·robots·구조화 데이터가 준비된다. |
| REQ-016 | 높음 | 화면은 한국어로만 제공한다. | 언어 전환 UI나 번역 페이지를 제공하지 않는다. |

## 콘텐츠와 UI 원칙

- 시공 사례 사진이 가장 중요한 콘텐츠다.
- AI 느낌의 장식보다 현장 사진과 간결한 정보 전달을 우선한다.
- 제품은 판매 대상이 아니라 시공 품질을 설명하기 위한 정보다.
- 사례·제품 필터에는 검색창을 추가하지 않는다.
- 전화 문의는 헤더에 항상 노출하므로 별도 플로팅 버튼은 두지 않는다.
