# GK 산업 콘텐츠 모델

초기 콘텐츠는 정적 JSON으로 관리한다. 아래 구조는 구현 전 기획 기준이며, 실제 필드명은 개발 단계에서 승인된 범위 안에서 확정한다.

## 1. 시공 사례

| 필드 | 필수 | 의미 | 예시 |
| --- | --- | --- | --- |
| id | 예 | 사례 고유값 | `hwaseong-factory-epoxy` |
| title | 예 | 지역·현장 유형·공법 제목 | `화성시 공장 에폭시` |
| tags | 예 | 현장 유형과 공법 태그 배열 | `["공장", "에폭시"]` |
| location | 예 | 공개용 장소 | `화성시 공장` |
| workDate | 예 | 최신 정렬용 시공일, 고객 화면 비표시 | `2026-07-15` |
| summary | 예 | 목록용 짧은 시공 설명 | `제조시설 바닥 보수` |
| description | 예 | 상세 시공 내용 | `…` |
| method | 예 | 적용 공법 | `에폭시 바닥 시공` |
| productIds | 예 | 사용 제품 ID 배열 | `["epoxy-floor"]` |
| images | 예 | 여러 장의 시공 사진 배열 | `[{"src":"/…","alt":"…"}]` |

### 대표 이미지 규칙

- 시공 사례는 목록 카드와 웰컴 페이지에 사용할 대표 사진의 위치를 `thumbnailIndex` 숫자로 지정한다.
- 화면은 `images[thumbnailIndex]`를 대표 사진으로 사용한다. 예: `"thumbnailIndex": 0`
- 이미지 경로와 대체 텍스트는 `images` 배열에서 한 번만 관리한다.

### 사례 필터 규칙

- 태그는 현장 유형과 공법을 함께 사용한다.
- 여러 태그를 선택하면 선택한 모든 태그가 있는 사례만 보여준다.
- 검색창은 제공하지 않는다.
- `필터 초기화`는 모든 선택 태그를 해제하고 최신순 전체 목록을 보여준다.

## 2. 사용 제품

| 필드 | 필수 | 의미 | 예시 |
| --- | --- | --- | --- |
| id | 예 | 제품 고유값 | `epoxy-floor` |
| name | 예 | 제품명 | `에폭시 바닥재` |
| image | 예 | 대표 이미지와 대체 텍스트 | `{"src":"/…","alt":"에폭시 바닥재 제품 이미지"}` |
| tags | 예 | 공법 태그만 사용 | `["에폭시"]` |
| purpose | 예 | 사용 목적 | `공장 바닥의 내구성 확보` |
| benefits | 예 | 장점 배열 | `["내구성", "내오염성"]` |
| composition | 예 | 제품 구성 설명 | `주제와 경화제` |
| applicationGuide | 예 | 권장 시공 기준 | `현장 조건별 2회 도포` |
| coverage | 예 | 시공 가능 면적 | `1세트 약 30㎡` |

### 제품 필터 규칙

- 공법 태그만 사용한다. 적용 공간·성능은 태그가 아닌 상세 설명에 둔다.
- 여러 태그 선택, AND 방식, 필터 초기화는 시공 사례와 동일하다.
- 제품 판매·가격·장바구니·다운로드 기능은 제공하지 않는다.

## 3. 사이트 정보

| 필드 | 초기값 | 교체 시점 |
| --- | --- | --- |
| companyName | `GK 산업` | 확정 |
| phone | `1588-0000` | 실제 대표번호 확보 시 |
| serviceArea | `대한민국 전국` | 확정 |
| address | 임시 주소 | 실제 주소 확보 시 |
| businessInfo | 임시 사업자 정보 | 실제 정보 확보 시 |
| social.youtube | `준비 중` | 실제 주소 확보 시 |
| social.instagram | `준비 중` | 실제 주소 확보 시 |
| keywords | 바닥 시공, 에폭시 바닥, 우레탄 바닥, MMA 바닥 등 | 검색 전략 변경 시 |
| about.title | 임시 회사 소개 제목 | 실제 소개 방향 확정 시 |
| about.paragraphs | 임시 회사 소개 문단 배열 | 실제 소개 문구 확정 시 |

회사 소개 문구는 UI 코드에 직접 쓰지 않고 `about` 데이터로 관리한다. 실제 실적·인증·연혁이 확인되기 전에는 임시 예시 문구를 사용한다.

## 인계

- 완료: 사례·제품·사이트 정보의 JSON 기준 정의
- 확정: 다중 AND 필터, 최신 정렬, 고객 화면 시공일 숨김
- 미확정: 실제 사진, 제품 사양, 회사 정보, 외부 채널 주소
- 다음 역할 입력: 디자인에 필요한 사례·제품 카드 정보
- 다음 행동: 기획 리뷰 통과 후, 사용자의 디자인 단계 진행 승인을 기다린다.
