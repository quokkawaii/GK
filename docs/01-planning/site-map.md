# GK 산업 사이트맵과 정보 구조

## 1. 페이지 구조

| 경로 | 페이지 목적 | 핵심 정보와 행동 |
| --- | --- | --- |
| `/` | GK 산업의 시공 전문성과 최신 콘텐츠를 빠르게 전달 | 임시 첫 화면 소개, 최근 시공 사례 3개, 사용 제품 3개, 고정 헤더 전화 문의 |
| `/cases` | 방문자가 원하는 시공 사례를 찾게 함 | 현장 유형·공법 다중 태그 필터, 필터 초기화, 최신순 사례 카드 |
| `/cases/[id]` | 한 시공 사례의 상세 정보 제공 | 여러 장의 시공 사진, 제목, 태그, 장소, 시공 내용, 공법, 사용 제품 |
| `/products` | 방문자가 시공 시 사용 제품을 찾게 함 | 공법 다중 태그 필터, 필터 초기화, 제품 카드 |
| `/products/[id]` | 한 사용 제품의 소개 정보 제공 | 제품 이미지, 제품명, 공법 태그, 사용 목적, 장점, 구성, 시공 기준, 시공 가능 면적 |
| `/about` | GK 산업의 기본 회사 정보를 제공 | 임시 소개 문구, 임시 주소·사업자 정보, 유튜브·인스타그램 준비 중 안내 |

## 2. 전역 구조

### 헤더

- 데스크톱: GK 산업 로고, 시공 사례, 사용 제품, 회사 소개, 전화 문의.
- 모바일: 로고, 전화 문의, 메뉴 버튼.
- 헤더는 화면 상단에 고정한다.
- 모바일 메뉴는 오른쪽에서 열리는 패널이다.
- 전화 문의 버튼은 모바일에서 전화 연결을 실행하고, PC에서는 대표번호 안내로 보인다.

### 푸터

- GK 산업명, 임시 대표번호, 임시 주소, 임시 사업자 정보.
- 유튜브·인스타그램은 실제 주소 전까지 `준비 중`으로 표시한다.
- 홈의 회사 소개 섹션은 제공하지 않는다. 회사 소개는 독립 페이지에서 제공한다.

## 3. 홈 정보 구조

1. 첫 화면 소개: 임시 제목과 간단한 안내 문구.
2. 최근 시공 사례: 대표 사진·제목·태그가 있는 사례 카드 3개와 `시공 사례 보기` 이동 UI.
3. 시공 시 사용 제품: 제품 이미지·제품명·공법 태그·사용 목적 한 줄이 있는 카드 3개와 `제품 보러가기` 이동 UI.
4. 푸터.

## 4. 목록과 상세 흐름

### 시공 사례

`시공 사례 목록 → 다중 태그 필터 → 선택 태그를 모두 가진 사례만 표시 → 카드 클릭 → 상세 페이지`

- 카드: 대표 사진, `화성시 공장` 형식의 제목, 태그.
- 최신 시공일 기준으로 정렬하며 시공일은 고객 화면에 보이지 않는다.
- 상세 페이지 아래에 관련 사례를 별도로 노출하지 않는다.

### 사용 제품

`사용 제품 목록 → 공법 다중 태그 필터 → 선택 태그를 모두 가진 제품만 표시 → 카드 클릭 → 상세 페이지`

- 카드: 제품 이미지, 제품명, 공법 태그, 사용 목적 한 줄.
- 제품 태그는 공법만 사용한다.
