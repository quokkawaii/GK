# GK 산업 홈페이지 기획 요약

## 서비스 한 문장

GK 산업의 바닥 시공 사례와 시공 시 사용 제품을 사진 중심으로 소개하고 전화 문의로 연결하는 한국어 웹사이트.

## 목표

- 1차 목표: 방문자가 시공 전문성과 사례를 확인한 뒤 전화 문의를 하게 한다.
- 핵심 고객: 특정하지 않지만 건설사와 공장 운영자를 우선 고려한다.
- 활동 범위: 대한민국 전국.

## 확정된 결정

| ID | 결정 |
| --- | --- |
| DEC-001 | 초기 콘텐츠는 정적 JSON으로 관리한다. DB, MongoDB, REST API는 도입하지 않는다. |
| DEC-002 | 전화 문의만 제공한다. 대표번호는 임시 `1588-0000`이다. |
| DEC-003 | 기본 메뉴는 시공 사례, 사용 제품, 회사 소개다. |
| DEC-004 | 초기 버전은 한국어만 제공한다. |
| DEC-005 | 사례와 제품 목록에는 검색창 없이 다중 태그 필터와 필터 초기화를 제공한다. |
| DEC-006 | 여러 태그를 고르면 모든 태그를 가진 항목만 표시한다. |
| DEC-007 | 모바일 메뉴는 오른쪽 패널 방식이며, 헤더는 고정한다. |
| DEC-008 | 회사 소개는 기본 메뉴와 독립 페이지로 제공한다. 웰컴 페이지의 회사 소개 섹션만 제외하며, 푸터의 임시 회사 정보는 유지한다. |
| DEC-009 | 기획 단계의 사이트맵과 정보 구조를 승인한다. 다음 역할은 기획 리뷰어다. |
| DEC-010 | `company-intro-example.md`의 임시 회사 소개 문구를 초기 회사 소개 페이지 내용으로 사용한다. |

## 첫 출시 범위

- 첫 화면: 사진 중심 소개, 최근 시공 사례, 시공 시 사용 제품, 전화 문의.
- 시공 사례: 목록, 다중 태그 필터, 상세 화면, 여러 장의 시공 사진.
- 사용 제품: 목록, 공법 태그 필터, 상세 소개 화면.
- 회사 소개: 임시 회사 소개 내용과 임시 주소·사업자 정보를 제공하는 독립 페이지.
- 푸터: 임시 주소·사업자 정보, 준비 중인 유튜브·인스타그램 안내.
- 검색 노출 기본 구조: 페이지 제목·설명, 의미 있는 URL, 이미지 대체 텍스트, 사이트맵, robots, 구조화된 업체 정보.

## 제외 범위

- 제품 판매, 장바구니, 결제, 회원 가입, 로그인.
- 견적 신청 폼, 카카오톡 상담, 온라인 채팅.
- 데이터베이스, REST API, 인증, 파일 업로드.
- 전후 사진 비교 기능, 영어 등 다국어 기능.
