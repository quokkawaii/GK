# GK 산업 회사 소개 임시 예시

## 사용 원칙

- 이 문서는 실제 회사 연혁·인증·실적을 주장하지 않는 임시 예시다.
- 실제 대표 인사말과 회사 정보가 준비되면 해당 내용으로 교체한다.
- 소개 페이지는 길게 쓰기보다, 방문자가 어떤 시공을 하는 회사인지 빠르게 이해하도록 구성한다.
- 상태: `DEC-010`에 따라 아래 임시 예시 문구를 초기 회사 소개 페이지 내용으로 사용한다.

## 일반 시공사 소개의 구성 분석

일반 건설·시공 회사 소개는 보통 아래 순서로 구성된다.

1. 인사와 회사명
2. 주력 현장 또는 제공 분야
3. 현장 중심의 원칙: 안전, 품질, 신뢰, 일정, 소통 등
4. 고객에게 드리는 약속과 문의 안내

GK 산업에는 확인되지 않은 연혁·인증·수치 대신, 바닥 시공 범위와 현장 조건을 고려한다는 기본 설명만 사용한다.

## 임시 예시 문구

### 제목

현장을 이해하는 바닥 시공, GK 산업

### 인사말

안녕하세요. GK 산업입니다.

GK 산업은 공장, 주차장, 주방, 옥상 등 다양한 공간의 바닥 시공을 소개하고 있습니다. 바닥은 공간의 용도와 사용 환경에 따라 필요한 공법과 마감 기준이 달라집니다.

저희는 현장 조건과 사용 목적을 살펴보고, 필요한 시공 방향과 사용 제품 정보를 안내하는 데 집중합니다. 시공 사례와 제품 정보를 통해 고객이 필요한 내용을 쉽게 확인할 수 있도록 하겠습니다.

전국 어디서나 바닥 시공 관련 문의가 필요하시면 GK 산업으로 연락해 주세요.

### 안내 문구

시공 사례와 사용 제품 정보를 확인하신 뒤, 전화로 편하게 문의해 주세요.
