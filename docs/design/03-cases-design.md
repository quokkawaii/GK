# 시공 사례 디자인

# REQ-common-028

- 우선순위: 상
- 제목: 시공 사례 상세의 독립 공개 URL·색인 미제공
- 디자인 상태: 미확인

## 디자인 방법

시공 사례 상세는 사례별 독립 공개 URL과 별도 공유·색인 경로를 제공하지 않는다.

- 주소 표시줄은 시공 사례 기본 목록 URL을 유지한다.
- 시공 사례 상세에는 사례별 독립 URL, canonical URL, Open Graph 정보, 사이트맵 항목을 제공하지 않는다.

세부 시각 값과 반응형 표현은 `docs/design/design-system.md`와 기존 화면 시안을 기준으로 확인한다.

# REQ-common-030

- 우선순위: 중
- 제목: 시공 사례 필터 변경 뒤 첫 페이지 결과 표시
- 디자인 상태: 미확인

## 디자인 방법

방문자가 시공 사례 페이지에서 태그 필터를 추가하거나 해제하면, 선택 결과를 첫 페이지부터 표시하고 결과 요약 영역을 화면 상단에 보이게 한다.

- 시공 사례 페이지에서 장소 또는 자재 태그를 추가·해제하면 현재 페이지 번호를 1페이지로 초기화한다.
- 필터 변경 뒤 `전체 N건 / 1페이지` 결과 요약이 고정 헤더에 가려지지 않도록 화면 상단에 표시된다.
- 결과 요약 바로 아래에서 새 조건의 첫 사례 카드 또는 결과 없음 안내를 확인할 수 있다.
- 선택된 장소·자재 태그 토글은 필터 변경 뒤에도 그대로 표시된다.

세부 시각 값과 반응형 표현은 `docs/design/design-system.md`와 기존 화면 시안을 기준으로 확인한다.
