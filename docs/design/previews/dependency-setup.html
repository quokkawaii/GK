의존성·폴더 구조 설정 결과

Next.js 프로젝트의 기반 도구와 기능별 빈 폴더를 만들었습니다. 아직 고객 화면이나 실제 기능 코드는 작성하지 않았습니다.

준비된 설정

  • next.config.ts: Cloudflare Pages용 정적 내보내기와 이미지 서버 미사용
  • tsconfig.json: strict 모드, JSON 읽기, @/ 경로 별칭
  • config/prettier.config.mjs: LF·공백 2칸·100자·큰따옴표·세미콜론
  • config/eslint.config.mjs, config/vitest.config.ts, .husky/pre-commit

확인할 사항

의존성 설치는 완료됐고 취약점은 발견되지 않았습니다. Node.js LTS 재설치 후 전역 npm도 복구됐으며, npm run lint 실행을 확인했습니다. 다만 ESLint 내부 보조 패키지 하나의 설치 후 스크립트가 차단됐으므로, 실제 검사 실행 결과를 본 뒤 허용 여부를 결정합니다.
