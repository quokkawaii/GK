GK 산업 화면·기능 구조 비교

현재 화면이 어떤 파일에 어떤 기능을 모아 두었는지와, 개편 뒤 부모·화면·재사용 기능이 어디에 놓이는지를 비교한 산출물입니다. 구현 방법을 길게 설명하지 않고 “어디에 어떤 기능이 있는가”만 정리합니다.

개편 기준: 부모는 화면을 합치고 필요한 데이터만 전달합니다. 자식 화면은 자기 화면과 필요한 기능을 담당합니다. 사례·제품처럼 다른 곳에서도 쓸 수 있는 화면이나 기능은 따로 빼고 props만 바꿔 재사용합니다.

개편 후: 화면마다 가진 기능

각 화면이 무엇을 보여 주고 어떤 기능을 가지는지만 정리했습니다.

공통 화면

Header / MobileMenu / Footer

기능
  • 주소 이동 메뉴
  • 전화 문의 링크
  • 모바일 메뉴 열기·닫기
  • 모바일 메뉴의 Escape·뒤 화면 스크롤 잠금

홈

HomeHero / HomeRecentCases / HomeProducts

기능
  • 시공 사례 목록 이동
  • 최근 사례 상세 팝업 열기·닫기
  • 제품 카드에서 해당 사례 목록 이동

시공 사례

CaseFilters / CaseResults / CasePagination

기능
  • 장소 1개·제품 1개 선택
  • 선택 조건을 모두 만족하는 사례 표시
  • 페이지 이동·목록 위치 이동
  • 사례 상세 팝업 열기·닫기

사용 제품

ProductFilters / ProductResults

기능
  • 제품 선택·해제·전체
  • 선택 조건에 맞는 제품 표시
  • 제품 카드에서 해당 사례 목록 이동

회사 소개

CompanyIntroduction / ServiceScopes / Contact

기능
  • 회사 소개 문구 표시
  • 서비스 범위 표시
  • 필수 전화번호로 문의 연결

사례 상세

CaseDetailModal

기능
  • 팝업 틀·닫기
  • 사진 갤러리·큰 사진 보기
  • 시공 내용·장소·제품·태그 표시

재사용 때문에 따로 빼는 화면·기능

다른 곳에서도 같은 모습이나 동작을 쓸 수 있는 것만 분리합니다.

PageHero

사례·제품·회사 소개의 같은 첫 영역을 하나로 관리합니다.

각 페이지는 제목·설명 문구만 전달

ProductCard

홈과 제품 목록이 같은 제품 카드 화면을 사용합니다.

홈: 3열 / 제품 목록: 2열
그리드만 다르고 카드는 동일

ImageGallery

사진 영역과 사진 이동 기능을 하나의 공용 화면으로 둡니다.

사례: images={caseItem.images}
제품 상세: images={product.images}

useDialogFocus

팝업의 초점 이동·Tab 제한·Escape·닫은 뒤 초점 복귀 기능입니다.

사례 상세 팝업과 모바일 메뉴가 직접 사용

useBodyScrollLock

팝업이 열렸을 때 뒤 화면 스크롤을 잠그는 기능입니다.

모바일 메뉴·상세 팝업·큰 사진 보기가 직접 사용

useImageGallery

현재 사진, 이전·다음, 썸네일 선택 규칙을 제공합니다.

ImageGallery가 직접 사용

필터 상태 규칙: 사례 필터·현재 페이지와 제품 필터는 모든 새로고침과 모든 페이지 이동 뒤에도 유지합니다. 사례는 gk-case-list, 제품은 gk-product-list에 탭 단위로 저장합니다. 각 필터 화면의 초기화 버튼을 눌렀을 때만 해당 필터값을 지웁니다.
