GK INDUSTRY / PLAIN LANGUAGE GUIDE

쉬운 용어 사전

역할 지침과 홈페이지 제작 과정에서 나오는 말을 쉬운 표현으로 풀이했습니다.

핵심만 기억하면 됩니다. 기획자는 “무엇을 만들지”, 디자이너는 “어떻게 보일지”, 개발자는 “실제로 작동하게 만들기”, 리뷰어는 “약속대로 됐는지 확인하기”를 맡습니다.

일의 진행과 약속

REQ

Requirement · 요구사항

홈페이지에 반드시 있어야 하는 약속입니다. 번호를 붙이면 나중에 빠진 것이 없는지 확인하기 쉽습니다.

예: REQ-001 — 첫 화면에 전화 문의 버튼을 보여준다.

완료 기준

Acceptance Criteria

“이 요구사항이 제대로 끝났다”라고 판단하는 구체적인 기준입니다.

예: 휴대폰에서도 전화번호 버튼을 누르면 전화 앱이 열린다.

DEC

Decision · 확정 결정

사용자가 선택해서 더 이상 임의로 바꾸면 안 되는 중요한 결정입니다.

예: DEC-001 — 초기 데이터는 데이터베이스가 아닌 JSON 파일로 관리한다.

TBD

To Be Decided · 나중에 결정

아직 정하지 못한 항목입니다. 억지로 채우지 않고, 무엇을 물어봐야 하는지도 함께 적습니다.

예: TBD-001 — 실제 대표 전화번호는 무엇인가요?

REV

Review · 검토 의견

리뷰어가 발견한 확인·수정 필요 사항입니다.

예: REV-003 — 모바일에서 시공 사례 사진이 너무 작아 보입니다.

인계

Handoff

한 역할이 끝난 뒤 다음 역할에게 “무엇이 끝났고, 무엇이 남았는지” 알려주는 정리입니다.

예: 디자이너가 승인된 시안과 남은 질문을 개발자에게 전달합니다.

화면과 사용자 경험

CTA

Call To Action · 행동 버튼

방문자에게 다음 행동을 유도하는 버튼이나 링크입니다.

예: “전화 문의하기”, “시공 사례 보기” 버튼

사용자 흐름

User Flow

방문자가 사이트에서 어떤 순서로 정보를 보고 행동하는지 나타낸 길입니다.

예: 첫 화면 → 시공 사례 확인 → 전화 문의

와이어프레임

Wireframe · 화면 뼈대

색상이나 사진을 꾸미기 전, 제목·사진·버튼이 어디에 놓일지 보여주는 간단한 화면 설계도입니다.

예: “최근 시공 사례” 제목 오른쪽에 “사례 보기” 버튼을 둡니다.

HTML 시안

HTML Mockup · 검토용 화면

실제 사이트처럼 보이게 만든 미리보기입니다. 아직 고객이 사용하는 완성 홈페이지는 아닙니다.

예: 디자인을 고르기 위해 만든 B 방향 화면

반응형 화면

Responsive Design

컴퓨터, 태블릿, 휴대폰처럼 화면 크기가 달라도 보기 편하게 바뀌는 화면입니다.

예: 휴대폰에서는 시공 사례 카드가 한 줄에 하나씩 보입니다.

접근성

Accessibility

장애가 있거나 마우스를 쓰기 어려운 사람도 사이트를 이용할 수 있게 하는 기준입니다.

예: 사진에 설명을 넣고, 키보드만으로 버튼을 누를 수 있게 합니다.

데이터와 검색 노출

JSON

JavaScript Object Notation · 데이터 메모 형식

시공 사례 제목, 사진, 태그 같은 정보를 일정한 형식으로 모아두는 텍스트 파일입니다.

예: 새 시공 사례를 추가할 때 화면 코드를 고치지 않고 JSON에 사례 정보를 추가합니다.

API

Application Programming Interface · 데이터 연결 창구

웹사이트가 다른 서버나 서비스에서 정보를 받아오고 보내는 방법입니다.

예: 현재 단계에서는 사용하지 않고 JSON 파일을 직접 읽습니다.

데이터베이스(DB)

Database

많은 데이터를 저장하고 수정·검색하기 위한 시스템입니다.

예: 현재는 필요하지 않으며, 시공 사례는 JSON 파일로 관리합니다.

SEO

Search Engine Optimization · 검색 노출 기본 작업

구글·네이버가 홈페이지 내용을 이해하고 검색 결과에 보여주기 좋게 만드는 작업입니다. 순위를 보장하는 것은 아닙니다.

예: “공장 바닥 시공”처럼 페이지 제목과 내용의 주제를 분명히 적습니다.

메타데이터

Metadata · 페이지 설명 정보

검색 결과나 링크 미리보기에서 보이는 페이지 제목·설명 같은 숨은 정보입니다.

예: “GK 산업 | 전국 바닥 시공 전문”

사이트맵 · robots

Sitemap · robots.txt

검색 엔진에게 어떤 페이지가 있고, 어떤 페이지를 살펴보면 되는지 알려주는 안내 파일입니다.

예: 시공 사례 상세 페이지가 검색 엔진에 발견되도록 돕습니다.

대체 텍스트

Alt Text · 사진 설명

사진이 보이지 않거나 화면 읽기 기능을 쓸 때 대신 전달되는 짧은 설명입니다.

예: “공장 내부의 회색 에폭시 바닥 시공 완료 모습”

범위

Scope · 이번에 할 일의 경계

이번 작업에서 만들 것과 만들지 않을 것을 정한 선입니다. 범위 밖 일은 먼저 승인받습니다.

예: 초기 범위에는 제품 판매·온라인 결제·회원 가입이 없습니다.
