# 디자인 시스템

이 문서는 GK 산업 사이트 화면에 공통으로 적용할 디자인 기준을 기록한다. 색상·글꼴·글자 크기·여백·버튼·모서리 값은 `docs/design/references/toss.md`의 `toss.im` 마케팅 웹 기준을 사용한다. TDS Mobile 값은 섞지 않는다. 실제 코드 값은 개발 단계에서 `src/app/globals.css`의 Tailwind `@theme`에 같은 내용으로 적용한다.

## 정할 항목

| 영역          | 정할 내용                               | 상태 |
| ------------- | --------------------------------------- | ---- |
| 색상          | 기본 배경, 글자, 강조색, 테두리, 경고색 | 확정 |
| 글자          | 제목·본문·보조 문구 크기와 굵기         | 확정 |
| 간격          | 카드·섹션·화면 여백의 공통 단위         | 확정 |
| 모서리·테두리 | 카드와 버튼의 모서리, 선 두께           | 확정 |
| 버튼          | 전화 문의, 일반 버튼, 필터 버튼 상태    | 확정 |
| 사진          | 목록·상세 사진 비율, 대체 텍스트 기준   | 확정 |
| 반응형        | PC·모바일 전환 기준과 화면별 배치       | 확정 |

## 적용 원칙

- 시공 사진이 가장 먼저 보이도록 장식 요소를 과도하게 늘리지 않는다.
- 전화 문의는 강조색을 사용하되, 화면 전체에서 같은 방식으로 표시한다.
- 디자인 값은 화면마다 임의로 새로 만들지 않고 이 문서와 `src/app/globals.css`의 Tailwind 토큰 값을 재사용한다.

## 색상

색상값과 색상 역할은 `toss.md`의 `Color Palette & Roles`와 `tokens.colors`를 참조한다.

강조색은 전화 문의와 현재 선택 상태처럼 사용자의 다음 행동 또는 현재 상태를 알려야 하는 곳에만 사용한다. 넓은 배경에는 쓰지 않아 시공 사진보다 강하게 보이지 않게 한다.

## 글자

글꼴과 글자 크기·굵기·줄 간격은 `toss.md`의 `Typography Rules`를 참조한다. Toss Product Sans를 적법하게 제공할 수 없는 환경에서는 Pretendard와 운영체제 기본 한글 고딕을 대체 글꼴로 사용하며, 별도 글꼴 파일은 저장소에 추가하지 않는다.

## 간격

간격값은 `toss.md`의 `Layout Principles > Spacing System`과 `tokens.spacing`을 참조하며, 임의의 숫자를 새로 만들지 않는다.

- 같은 카드 안 요소는 좁은 간격 토큰을 사용한다.
- 카드 사이는 카드 내부보다 넓게 둔다.
- 구역 안 여백은 카드 사이보다 넓게 둔다.
- 화면 구역 사이는 가장 넓은 간격 토큰을 사용한다.

## 공통 요소

### 모서리와 테두리

- 카드·필터·안내 영역은 `toss.md`의 표면 반경을 사용한다.
- 버튼은 `toss.md`의 마케팅 웹 버튼 반경을 사용한다.
- 기본 테두리는 `toss.md`의 테두리 토큰을 사용한다.
- 진한 안내 영역은 `toss.md`의 마케팅 진한 배경을 사용한다.

### 버튼

| 구분      | 기준                                      | 용도                          |
| --------- | ----------------------------------------- | ----------------------------- |
| 전화 문의 | `toss.md`의 `Marketing Dark`              | 가장 중요한 전화 문의         |
| 진한 버튼 | `toss.md`의 `Marketing Dark`              | 시공 사례 보기 같은 주요 이동 |
| 일반 버튼 | `toss.md`의 `Marketing Primary`           | 사용 제품 보기, 일반 이동     |
| 글자 버튼 | 배경·테두리 없이 밑줄을 사용하는 GK 확장 | 회사 소개 등 보조 이동        |

- 페이지 번호는 마케팅 일반 버튼의 높이를 한 변으로 사용하는 정사각형 GK 확장값이다.

### 필터와 카드

- 선택되지 않은 필터는 `toss.md`의 Canvas와 Border 토큰으로 표시한다.
- 선택된 필터는 `toss.md`의 Weak Background와 Weak Foreground 토큰으로 표시한다.
- 시공 사례 필터의 초기화는 태그 필터 제목 옆에 밑줄 글자 버튼으로 둔다.
- 사용 제품 필터는 초기화 버튼을 두지 않고, 칩 첫 항목의 `전체`로 선택을 해제한다.
- 사진 카드는 1px 테두리, 사진, 태그, 제목, 짧은 설명 순서로 구성한다.
- 시공 사례 카드는 카드 전체를 눌러 같은 화면의 상세 팝업을 연다.
- 사용 제품 카드는 카드 전체를 이동 요소로 만들지 않는다. 카드 하단의 `시공 사례 보기` 링크 버튼만 선택 자재가 적용된 사례 목록으로 이동한다.
- 웰컴 페이지의 사용 제품 카드는 사용 제품 목록과 같은 카드 컴포넌트와 표시 순서를 재사용한다. 홈에서는 그중 일부만 노출한다.
- 사용 제품 전용 이미지가 없을 때는 카드의 예시 그래픽 아래에 `죄송합니다. 이미지는 준비 중입니다.`를 표시한다.

### 페이지 번호

- 페이지 번호는 마케팅 일반 버튼의 높이를 한 변으로 사용하는 정사각형 버튼으로 둔다.
- 현재 페이지는 `toss.md`의 Marketing Dark를, 나머지는 Canvas와 Border 토큰을 사용한다.

## 사진

| 위치                     | 표시 기준                               |
| ------------------------ | --------------------------------------- |
| 시공 사례·제품 목록 카드 | 4:3 비율로 카드 영역을 채워 표시        |
| 웰컴 페이지 대표 사진    | 16:10 비율로 넓게 표시                  |
| 상세 갤러리              | 원본 비율을 유지하고 사진을 자르지 않음 |
| 상세 썸네일              | 4:3 비율, 현재 사진은 파란 테두리       |

- 사진이 두 장 이상인 상세 갤러리에만 좌우 이동 버튼, 현재 위치(`1 / 6` 등), 썸네일을 표시한다. 사진이 한 장이면 해당 조작 요소를 숨기고 사진만 표시한다.
- 가로·세로 사진은 상세 갤러리의 진한 배경 여백 안에서 모두 보이게 표시한다.
- 상세 팝업은 닫기 버튼 또는 팝업 바깥 영역 클릭으로 닫는다.
- PC 상세 팝업은 웹사이트 본문 최대 폭 `1180px` 안에서 `width: 100%`를 사용한다. 화면 위·아래에는 각각 72px 여백을 남겨, 팝업 높이는 화면 높이보다 144px 작게 둔다. 팝업 안의 제목·갤러리·시공 내용·정보 표는 기존 사례 상세 화면 구성을 그대로 사용한다.
- 모바일 상세 팝업은 아래에서 열리는 시트형으로 둔다. 별도 머리말·태그 문구는 표시하지 않고, 사례 제목 오른쪽에 닫기 버튼을 둔다.
- PC 상세 팝업도 모바일과 같은 제목·닫기 구조를 사용한다. 별도 머리말·태그 문구를 표시하지 않는다.
- PC·모바일 모두 상세 팝업의 대표 사진을 누르면 전체 화면 사진 뷰어를 연다. 뷰어는 팝업 위에 표시되며, 닫으면 기존 상세 팝업으로 돌아온다.
- PC·모바일 모두 상세 팝업의 사례 제목과 닫기 버튼은 팝업 내부 스크롤 중에도 상단에 고정한다.
- 모바일 아래 시트는 상단 손잡이를 아래로 100px 이상 끌면 닫고, 그보다 짧게 놓으면 원래 위치로 돌아온다.
- PC에서는 `Esc` 키가 사진 확대 뷰어를 먼저 닫고, 뷰어가 열려 있지 않으면 시공 사례 상세 팝업을 닫는다.
- PC 사진 확대 뷰어에서는 `←`·`→` 키로 이전·다음 사진으로 이동한다. 화면의 화살표·썸네일·사진 위치 표시는 같은 현재 사진을 따르고, 현재 썸네일은 강조 테두리로 표시한다.
- 모바일 사진 확대 뷰어에서는 사진을 좌우로 밀어 이전·다음 사진으로 이동한다. 화면의 화살표·썸네일·사진 위치 표시는 같은 현재 사진을 따른다.
- 사진 확대 뷰어는 별도의 두 번 누르기 확대 기능 없이, 사진 전체가 화면 안에 보이는 크기로 표시한다.
- 시공 사례 목록의 카드는 전체를 누르면 해당 사례의 상세 팝업을 연다. 팝업은 해당 사례의 첫 번째 사진부터 표시한다.
- 상세 팝업을 닫아도 사용자가 보고 있던 시공 사례 목록의 필터, 페이지 번호, 스크롤 위치는 유지한다.
- 사진이 없는 사례는 `이미지가 없습니다` 안내 영역만 표시하며, 사진 확대·사진 넘김·사진 위치·썸네일 UI는 표시하지 않는다.
- 사이트의 고정 헤더와 전화 문의 CTA는 웰컴, 시공 사례 목록, 사용 제품, 회사 소개 화면에서만 표시한다. 시공 사례 상세 팝업에서는 표시하지 않는다.
- 전화 문의는 `src/content/site.json`의 대표 전화번호 한 값을 히어로 CTA·데스크톱·태블릿 오른쪽 CTA·회사 소개·푸터에서 함께 사용한다. 모바일에서는 히어로 CTA로 전화 앱을 연결하고, PC에서는 CTA에 번호만 표시한다.
- 대표 전화번호가 `null`이면 `전화번호 준비 중`을 표시하고, 전화 연결 동작은 제공하지 않는다.
- 상세 팝업 또는 사진 확대 뷰어가 열려 있는 동안에는 뒤의 시공 사례 목록 스크롤을 잠근다. 닫은 뒤에는 기존 목록 위치에서 다시 스크롤한다.
- 모든 사진에는 현장·시공 내용을 설명하는 대체 문구를 입력한다.

## 반응형

| 화면 폭      | 구분     | 적용 기준                                                |
| ------------ | -------- | -------------------------------------------------------- |
| 767px 이하   | 모바일   | 햄버거 메뉴, 화면 좌우 여백 16px, 목록 카드 2열          |
| 768px~1023px | 태블릿   | PC와 모바일 사이의 여백·카드 폭을 자연스럽게 조정        |
| 1024px 이상  | 데스크톱 | 헤더 아래 고정 메뉴, 최대 내용 폭 1,180px, 목록 카드 2열 |

위 화면 폭, 최대 내용 폭, PC 상세 팝업의 상하 여백은 `toss.md`에 보편 기준이 없으므로, 시공 사진 중심의 GK 공개 웹 레이아웃을 위한 프로젝트 확장값으로 유지한다.

- PC와 모바일은 메뉴, 필터, 페이지 번호, 사진 갤러리, 상세 정보, 전화 문의 등 같은 기능을 모두 제공한다.
- 모바일에서는 메뉴를 햄버거 버튼으로 열고, 필터 옵션은 가로 스크롤·드래그·마우스 휠로 이동한다.
- 시공 사례와 사용 제품 목록은 모바일에서도 카드 2열을 유지하고, 한 페이지에 4개씩 표시한다.
- 화면 폭에 따라 사진·글자·여백만 줄이거나 재배치하며, 기능을 빼지 않는다.
