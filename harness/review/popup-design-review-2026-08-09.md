## 수정 필요 항목

### REV-032 — 사례 카드에서 팝업을 다시 열 수 없음

- 상태: 해결
- 확인: PC·모바일 시안은 처음에 목록을 표시하고, 카드 전체 클릭으로 해당 사례의 팝업을 첫 사진부터 연다.

### REV-033 — 키보드 초점 이동 규칙이 시안 동작으로 검증되지 않음

- 심각도: 중간
- 상태: 개발 단계 이관
- 확인: 시안은 카드 클릭·팝업 위치·닫기 흐름을 검토하는 디자인 산출물이다. `Tab` 이동 제한과 닫은 뒤 원래 카드 초점 복귀는 실제 React 팝업 컴포넌트에서 구현하고 확인한다.
- 개발 확인: `docs/development/testing-policy.md`의 수동 접근성 확인 항목으로 이관했다.

## 구현 단계 확인 항목

- 사진이 한 장인 사례에서는 화살표·사진 위치·썸네일을 숨긴다.
- 사진이 없는 사례에서는 `이미지가 없습니다` 안내만 표시한다.
- 팝업을 닫은 뒤 필터, 페이지 번호, 목록 스크롤 위치를 유지한다.
- 대표 전화번호가 `null`이면 `전화번호 준비 중`으로 표시하고 전화 연결을 숨긴다.
