- 문제: 현재 페이지 번호가 내부적으로 0부터 시작하며, Zustand 저장소는 0 이하 값을 그대로 저장한다.

- 해결 방법: 현재 페이지를 1부터 관리하고, 0 이하 또는 전체 페이지 수보다 큰 값은 현재 페이지를 유지하도록 했다.
